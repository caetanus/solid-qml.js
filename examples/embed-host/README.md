# embed-host: solid-qml inside an existing Qt Quick app

A plain Qt Quick application (standing in for a pre-existing C++ project) that hosts one piece of
solid-qml UI, a `SolidIsland`. It shows the whole embedding surface of `libsolidqml`:

1. Link `libsolidqml` (pkg-config `solidqml`, or `find_package(SolidQml)` in CMake). In this tree
   the demo links the in-tree library; see `embed-host-demo` in `meson.build`.
2. Call `SolidQmlEmbed::init(&engine, appDir)` once after creating the engine and before loading
   the host's QML (`main.cpp`). `appDir` is where relative island sources and CSS files resolve.
   An optional third argument selects the capability profile (`"browser"`, `"desktop"`,
   `"trusted"`).
3. Put a `SolidIsland` in the host scene (`main.qml`):

   ```qml
   import solidqml.Embed 1.0

   SolidIsland {
       source: "Counter.qml"               // a component generated by the transpiler
       cssFiles: ["App.generated.css"]     // its stylesheet
       onReady: rootItem.label = "host-driven"   // the component root: read/write its props
   }
   ```

Islands share one CSS cascade, so namespace your rules by class as you would on the web. Viewport
units (`vw`/`vh`) resolve against the host window.

## Run it

The demo is built with the rest of the tree (the `examples` option is enabled by default). It reads
`Counter.qml` from `qml/solidqml/`, the transpiler output that is checked into the repository
(`node --import tsx scripts/gen.mjs` regenerates it from `src/mainqml.tsx`). From the checkout:

```sh
./build/embed-host-demo                       # opens the host window
QT_QPA_PLATFORM=offscreen ./build/embed-host-demo --probe --grab shot.png
```

`--probe` has the host write the island's `count` property and checks that the generated binding
reacts. It prints `PROBE binding reacted: 'host-driven: 41'` and then `'host-driven: 42'` after the
solid click handler runs. `--grab` saves one frame to a PNG.

The opposite direction, using hand-written QML or a QML plugin from TSX, is in
`examples/native/customqml.tsx` (`import Badge from "./Badge.qml"`) and `examples/legacy-plugin/`
(`import { AcmeGauge } from "qml:Acme"` with `solid-qml-loader --import-path`).
